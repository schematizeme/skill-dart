**schematize-dart** — o piso de Dart/Flutter da casa.

| Comando | O que faz |
|---|---|
| `/dart-help` | esta lista |
| `/dart-load` | carrega TODO o corpo normativo (piso, plataforma) e passa a aplicá-lo |
| `/dart-review` | roda `scripts/check-dart.sh` e revisa o que a máquina não lê |
| `/dart-claude` | cria ou mescla o `CLAUDE.md` sempre-on na raiz do repo |
| `/dart-cc` · `/dart-handoff` | context compact / handoff no archive |

**A fronteira:** no que é de **app** (offline-first, IAM, push, lojas, teste no device), quem manda é
a **`schematize-mobile`**. Aqui é linguagem e toolchain.
